# MOMO

Real-time AI voice assistant built with Python, PyTorch, Moshi, Mimi, and WebSockets.

## How it works

```
Microphone
    ↓
Opus Audio
    ↓
Mimi
    ↓
Moshi
    ↓
Text + Audio
```

MOMO processes audio as a stream and generates both text and audio responses.

## Tech Stack

* Python
* PyTorch
* Moshi
* Mimi
* FastAPI
* WebSockets
* SentencePiece
* Modal
